# Nơi nhận tài liệu chưa kiểm

Đặt kết quả chat hoặc tài liệu được phép lưu ở đây, giữ nguyên bản. Không đặt key, thông tin học sinh hoặc đề mật trong repo chia sẻ.

Mỗi đầu vào chỉ cần ghi:

```text
Mã gói:
Người/công cụ cung cấp:
Ngày nhận:
Prompt/yêu cầu đã dùng:
Phạm vi:
Tên tệp/URL nguồn kèm theo:
Đã đọc gì / chưa đọc gì theo lời bên cung cấp:
Ghi chú của chủ dự án:
Trạng thái: CHUA_KIEM
```
